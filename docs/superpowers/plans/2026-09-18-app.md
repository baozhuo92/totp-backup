# Flutter App 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 实现 TOTP 备份 Flutter Android App：扫码/手动添加 TOTP → 本地离线出码 → 端到端加密自动备份到自建服务端 → 换机口令恢复 → 加密文件导入导出。

**架构：** 单 Activity 常规 Flutter App。UI 层（`ui/`）调用服务层（`services/`），服务层调用数据层（`data/`：本地 sqflite + 远端 dio）与核心层（`core/`：加密、主题）。账户 secret 在本地也以密文存储（主口令派生密钥 AES-256-GCM 加密）；同步服务在增/改/删后自动推送服务端；恢复流程为"拉取密文 → 口令解密 → 批量导入"。UI 遵循 zolysoft 规范：简约风格、简体中文、无 emoji、品牌色深青 `#0F766E`、支持暗黑模式。

**技术栈：** Flutter（Android）、`otp`（TOTP 计算，主人已确认）、`cryptography`（PBKDF2+AES-256-GCM）、`mobile_scanner`（扫码）、`local_auth`（指纹）、`sqflite`（本地库）、`dio`（HTTP）、`path_provider`（文件路径）、`flutter_secure_storage`（安全存储 API Key/服务端地址）。版本：全部采用 pub.dev 当前稳定主版本并锁定（`flutter pub add` 装时为准）。

**验证原则（主人已去掉自动化测试计划）：** 每任务以 `flutter analyze` 静态检查 + `flutter build apk --debug` 构建验证；交互流程在 Android 真机/模拟器手动验证。Flutter 环境位于 `C:\Users\Administrator\Documents\Servers\flutter\bin\flutter.bat`（首次运行初始化较慢属正常）。
