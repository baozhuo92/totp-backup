# Go 服务端实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 实现 TOTP 备份服务端：单用户 API Key 鉴权的账户备份 REST API + SQLite 存储 + Docker Compose 部署。

**架构：** Go + Gin 提供 REST API；SQLite（modernc.org/sqlite 纯 Go 驱动，无 CGO，Docker 构建简单）存储加密账户与日志；雪花 ID 在应用层生成（bwmarrin/snowflake）；API Key 通过环境变量配置、Header `X-API-Key` 鉴权；请求日志中间件写 t_api_log，账户变更写 t_change_log；所有账户 secret 为端到端加密密文，服务端不接触明文。

**技术栈：** Go 1.27、Gin v1（^1.10.0）、modernc.org/sqlite（^1.34.0）、bwmarrin/snowflake（^1.3.0）、Docker + docker-compose

**验证原则（主人已去掉自动化测试计划）：** 每个任务以 `go build ./...` + `go vet ./...` 构建验证，接口以 `curl` 手动验证。本机未安装 Docker，任务 7 仅交付文件并静态自检，实际部署验证在目标服务器执行（如实标注）。

## 文件结构

```
server/
├── go.mod                     # 模块定义与依赖锁定
├── .env.example               # 环境变量模板（API_KEY 等）
├── Dockerfile                 # 多阶段构建（golang:1.27-alpine → distroless/alpine）
├── docker-compose.yml         # 单服务编排 + 数据卷 + healthcheck
├── main.go                    # 入口：加载配置、初始化 DB、组装路由、启动
└── internal/
    ├── config/config.go       # 配置加载（PORT/API_KEY/DB_PATH，环境变量）
    ├── model/model.go         # Account 模型（JSON 契约）
    ├── db/db.go               # SQLite 连接 + 建表迁移（3 张表 DDL）
    ├── db/account_repo.go     # t_account 数据访问（Upsert/Delete/List）
    ├── db/change_log.go       # t_change_log 写入
    ├── handler/middleware.go  # API Key 鉴权 + 请求日志中间件
    ├── handler/account.go     # /api/accounts/* handlers
    └── handler/health.go      # /api/health handler
```

**职责边界：** config 只负责读环境变量；db 只做 SQL 访问不写业务逻辑；handler 负责 HTTP 解析、调用 db、拼响应；middleware 负责鉴权与日志。所有时间戳用 Unix 毫秒。

```go
package config

import (
	"errors"
	"os"
)

// errMissingAPIKey：API_KEY 未配置时返回，阻止无鉴权启动（安全底线）
var errMissingAPIKey = errors.New("API_KEY 未配置")

// Config 服务端配置，全部来自环境变量（.env 由 docker-compose 注入）
type Config struct {
	Port   string // 监听端口，默认 8080
	APIKey string // 单用户 API Key，必填；App 通过 X-API-Key 头携带
	DBPath string // SQLite 文件路径，默认 ./data/totp.db
}

// Load 从环境变量读取配置；API_KEY 缺失时返回 error 阻止启动（安全底线：不允许无鉴权运行）
func Load() (*Config, error) {
	cfg := &Config{
		Port:   getEnv("PORT", "8080"),
		APIKey: os.Getenv("API_KEY"),
		DBPath: getEnv("DB_PATH", "./data/totp.db"),
	}
	if cfg.APIKey == "" {
		return nil, errMissingAPIKey
	}
	return cfg, nil
}

func getEnv(key, def string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return def
}
```

### 任务 2：数据库层（连接 + 3 张表迁移）

**文件：**

- [ ] **步骤 1：实现连接与迁移 `internal/db/db.go`**

要点：
- 使用 `modernc.org/sqlite` 驱动，DSN：`file:<path>?_pragma=busy_timeout(5000)&_pragma=journal_mode(WAL)`
- `Migrate` 执行以下 DDL（字段与索引完全遵循设计文档 §5，含 `--` 注释）

```sql
CREATE TABLE IF NOT EXISTS t_account (
    id                 INTEGER PRIMARY KEY,             -- 主键，应用层雪花 ID
    client_id          VARCHAR(64)  NOT NULL,           -- App 本地 UUID，客户端幂等键
    issuer             VARCHAR(200) NOT NULL,           -- 服务商名称
    account            VARCHAR(200) NOT NULL,           -- 账号名/邮箱
    secret_ciphertext  TEXT         NOT NULL,           -- 端到端加密密文（v1:salt:nonce:cipher）
    algorithm          VARCHAR(20)  NOT NULL DEFAULT 'SHA1', -- SHA1/SHA256/SHA512
    digits             INTEGER      NOT NULL DEFAULT 6, -- 验证码位数
    period             INTEGER      NOT NULL DEFAULT 30,-- 刷新周期秒
    created_by         INTEGER      NOT NULL DEFAULT 0, -- 创建人（单用户固定 0）
    created_time       INTEGER      NOT NULL,           -- 创建时间（毫秒）
    update_by          INTEGER      NOT NULL DEFAULT 0, -- 修改人（单用户固定 0）
    update_time        INTEGER      NOT NULL,           -- 修改时间（毫秒）
    delete_time        INTEGER      NOT NULL DEFAULT 0  -- 软删除标记（0=未删除）
);
CREATE UNIQUE INDEX IF NOT EXISTS uk_t_account_client_id ON t_account(client_id);
CREATE INDEX IF NOT EXISTS idx_t_account_delete_time ON t_account(delete_time);

CREATE TABLE IF NOT EXISTS t_api_log (
    id            INTEGER PRIMARY KEY,
    path          VARCHAR(200) NOT NULL,                -- 请求路径
    method        VARCHAR(10)  NOT NULL,                -- 请求方法
    request_body  TEXT,                                 -- 请求体（secret 为密文，无明文泄露）
    status_code   INTEGER      NOT NULL,
    cost_ms       INTEGER      NOT NULL,
    client_ip     VARCHAR(64)  NOT NULL,
    created_time  INTEGER      NOT NULL                 -- 请求时间（毫秒）
);
CREATE INDEX IF NOT EXISTS idx_t_api_log_created_time ON t_api_log(created_time);

CREATE TABLE IF NOT EXISTS t_change_log (
    id             INTEGER PRIMARY KEY,
    table_name     VARCHAR(100) NOT NULL,               -- 变更表名
    record_id      VARCHAR(64)  NOT NULL,               -- 变更记录 ID
    operation_type VARCHAR(10)  NOT NULL,               -- INSERT/UPDATE/DELETE
    old_data       TEXT,                                -- 变更前 JSON
    new_data       TEXT,                                -- 变更后 JSON
    created_time   INTEGER      NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_t_change_log_created_time ON t_change_log(created_time);
```

```go
}
```

- [ ] **步骤 2：实现数据访问 `internal/db/account_repo.go`**

函数（均接收 `*sql.DB`）：
- `UpsertAccount(ctx, db, node *snowflake.Node, a *model.Account) error`：按 `client_id` 查是否存在——存在则 UPDATE（更新 update_time），不存在则 INSERT（雪花 ID + created_time/update_time = now）。每次写入后调用 `WriteChangeLog`（INSERT 或 UPDATE，new_data 为账户 JSON）。
- `DeleteAccount(ctx, db, clientID string) (bool, error)`：`UPDATE t_account SET delete_time=?, update_time=? WHERE client_id=? AND delete_time=0`，受影响行数为 0 返回 false；成功后写 DELETE 变更日志。
- `ListAccounts(ctx, db) ([]model.Account, error)`：`SELECT ... WHERE delete_time=0 ORDER BY issuer, account`，**密文原样返回**。

注意：所有时间用 `time.Now().UnixMilli()`；雪花节点 id 固定为 1（单实例）。

- [ ] **步骤 1：实现中间件**

```go
package handler

// AuthMiddleware 单用户 API Key 鉴权；缺失/不匹配返回 401，拒绝继续
// 固定密钥由环境变量注入，比较用 subtle.ConstantTimeCompare 防时序侧信道
func AuthMiddleware(apiKey string) gin.HandlerFunc {
	return func(c *gin.Context) {
		got := c.GetHeader("X-API-Key")
		if got == "" || subtle.ConstantTimeCompare([]byte(got), []byte(apiKey)) != 1 {
			c.AbortWithStatusJSON(401, gin.H{"error": "unauthorized"})
			return
		}
		c.Next()
	}
}

// RequestLogger 记录每个请求到 t_api_log；请求体仅记录且需在 body 读回后继续（用 io.TeeReader 或读后 Reset）
// 响应状态码与耗时通过自定义 ResponseWriter 包装捕获
func RequestLogger(db *sql.DB, node *snowflake.Node) gin.HandlerFunc { /* 实现：读 body → c.Next() → 写 t_api_log */ }
```

注意坑点：Gin 中读取 body 后需 `c.Request.Body = io.NopCloser(bytes.NewBuffer(body))` 复位，否则后续 handler 读不到 body；请求体记录前无需脱敏——secret 本身是密文。

- [ ] **步骤 1：编写 Dockerfile（多阶段，modernc 驱动无需 CGO）**

```dockerfile
# 构建阶段
FROM golang:1.27-alpine AS builder
WORKDIR /build
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-s -w" -o /totp-server .

# 运行阶段
FROM alpine:3.20
RUN apk add --no-cache ca-certificates tzdata
WORKDIR /app
COPY --from=builder /totp-server .
# 数据目录由 docker-compose 卷挂载，非 root 运行更安全（可加 USER nobody，但需卷权限配合）
EXPOSE 8080
ENTRYPOINT ["/app/totp-server"]
```
